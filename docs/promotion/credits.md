# プロモーション映像のクレジット

『弓守 — 江戸の残照』のゲーム内映像を演出・編集した、約2分のプロモーションビデオです。

- 動画：`YUMIMORI_Promotion_120s.mp4`（2:00、1920×1080、24fps、H.264 / AACステレオ）
- 日本語字幕は映像に焼き込み済み。別添の `subtitles.ja.srt` も利用できます。
- 武器の性能・敵体力はノーマル基準。貫通実演は訓練モードで収録し、決戦は演出・編集しています。
- 音楽と効果音は本映像用に音響合成で制作。外部の楽曲・音声サンプルは使用していません。
