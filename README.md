# 弓守 — YUMIMORI

**一矢に、江戸を懸ける。**

Babylon.jsで制作した、江戸時代をテーマにしたブラウザ向けの一人称アクションゲームです。夕暮れの宿場町を舞台に、竹弓・火縄銃・手裏剣・焙烙火矢を使い分け、侍や山賊、騎馬兵、将軍、赤鬼を迎え撃ちます。

![ゲーム画面とモード選択](docs/screenshot.png)

[デプロイ済みゲームを開く](https://edo-yumimori.richgnome1024.chatgpt.site/) — 現在の公開先は所有者限定です。許可されたChatGPTアカウントでのログインが必要です。

## ローカルで遊ぶ

WebGL対応のデスクトップブラウザと、マウス・キーボードを使用してください。配信にはPython 3、テストにはNode.js 18以降を使用します。

```sh
git clone https://github.com/syunto0624-rgb/YUMIMORI.git
cd YUMIMORI
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

ブラウザで **http://127.0.0.1:8080** を開き、モードを選んで「街道を守る」または「訓練を始める」を押します。停止はターミナルで `Ctrl+C` です。

Node.js / npmがある環境では `npm start` でも同じサーバーを起動できます。`npm install` やビルドは不要です。HTMLを直接開くのではなく、HTTPサーバー経由で起動してください。

Babylon.js本体はリポジトリに同梱しています。Google Fontsの取得にはインターネット接続を使用しますが、取得できない場合は代替フォントで表示します。

## キャラクターの見た目

キャラクターはテクスチャ付きの高精細3Dモデルを使用します。甲冑・布・革・肌の表面をPBRマテリアルで描画し、歩行・走行アニメーションと戦闘時の姿勢を接続しています。侍・馬はブラウザ向けに軽量化済みです。

ゲーム下部の「敵将録 → 立体で見る」から、5種の敵を回転・拡大して確認できます。直接 `character-viewer.html` を開いても使えます。3Dモデルとテクスチャはすべて同梱し、実行時に外部のモデル配布元へアクセスする必要はありません。

3D素材の出典・改変内容・ライセンスは [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) を参照してください。KashiroZenのモデルはCC BY 4.0、Grab3DのモデルはCC0です。

## 操作

| 操作 | キー・マウス |
| --- | --- |
| 移動 | W / A / S / D |
| 走る | Shift |
| 視点操作 | マウス移動 |
| 竹弓 | 左ボタン長押しで溜め、離して射撃 |
| 火縄銃・焙烙火矢 | 左クリックで攻撃 |
| 手裏剣 | 左クリックで投擲、長押しで連射 |
| 狙いを定める | 右ボタン長押し |
| 武器切り替え | 1：竹弓、2：火縄銃、3：手裏剣、4：焙烙火矢 |

通常はPointer Lockでマウスを固定します。ブラウザや埋め込み環境がマウス固定に対応していない場合は、画面をドラッグして視点を動かせます。武器切り替えは画面内のボタンからも行えます。

## ステージ進行・銭・兵器解放

実戦は敵1体との戦闘を1ステージとして進行します。敵を倒すと攻略となり、銭を受け取って武器商で兵器を解放してから、次の戦場へ進めます。戦場は **平原 → 沼地 → 川辺** の順に交代します。

| 戦場 | 特徴 | 通常報酬 |
| --- | --- | --- |
| 平原 | 広い草原と岩の遮蔽 | 75銭 |
| 沼地 | 木道を外れると移動速度62% | 90銭 |
| 川辺 | 橋と浅瀬。浅瀬は移動速度50% | 100銭 |

将軍の攻略は250銭、赤鬼は400銭。鬼モードの報酬は2倍です。初回の実戦では竹弓だけを使用できます。手裏剣は120銭、火縄銃は300銭、焙烙火矢は450銭で解放します。実際のお金を使う機能はありません。

銭と解放済み兵器はブラウザのlocalStorageに保存され、敗北や再出陣でも保持します。攻略位置は出陣ごとに第1戦へ戻ります。保存が使えない環境ではページを開いている間のみ保持し、画面に案内を表示します。端末・ブラウザ間の同期はありません。

## ゲームモード

| モード | 内容 |
| --- | --- |
| 訓練 | 全5種の静止標的。全武器を試用でき、敵の攻撃・自爆ダメージなし。標的は自動復活。銭・攻略報酬なし |
| ノーマル | 全18戦。第11戦に将軍、最終戦に赤鬼。第6戦・第12戦の開始時に体力25回復（上限100） |
| 鬼 | 全24戦。敵体力・攻撃力1.5倍、速度1.2倍。章間回復なし。報酬2倍 |

最終ステージで赤鬼を倒し「戦果を見る」を選ぶと勝利です。体力が0になると敗北です。

## 武器

弾数は無限です。クールタイムは武器ごとに管理され、持ち替えても継続します。一時停止中は進行しません。数値はゲーム内設定です。

| 武器 | 胴への攻撃力 | 頭部 | 飛翔距離の上限 | クールタイム | 特性 |
| --- | --- | --- | --- | --- | --- |
| 竹弓 | 約46〜83 | 150 | 60m | 0.55秒 | 最大溜め0.9秒。溜めで威力・弾速が上がる |
| 火縄銃 | 160 | 240 | 100m | 3.6秒 | 最大3体の敵を貫通。2体目以降は直前の70%の威力 |
| 手裏剣 | 28 | 56 | 24m | 0.22秒 | 長押し連射。侍・騎馬兵・将軍の胴には威力65% |
| 焙烙火矢 | 直撃25＋爆風35〜130 | 直撃25 | 42m | 4.5秒 | 半径5.5mの爆発。着弾または飛翔2秒で爆発 |

- 射程は飛翔距離の上限です。重力や地形により、上限に達する前に着地することがあります。
- 火縄銃は敵を貫通しますが、建物などの遮蔽物は貫通しません。同じ敵の複数部位には重複命中しません。
- 爆風は中心から離れるほど減衰し、遮蔽物に防がれます。近距離では最大55の自爆ダメージがあります（訓練モードは無効）。
- ボスの頭部に命中しても即死はせず、武器ごとの頭部ダメージを与えます。

## 敵

以下はノーマル時の基礎値です。

| 敵 | 体力 | 攻撃力 | 特徴・回避方法 |
| --- | --- | --- | --- |
| 山賊 | 62 | 13 | 身軽な接近兵。連射や精密射撃で迎撃 |
| 侍 | 100 | 19 | 甲冑を着た刀兵。頭部や強力な武器で対処 |
| 騎馬兵 | 220 | 28 | 予備動作の後、狙った方向へ高速突進。横移動で回避 |
| 将軍（中ボス） | 600 | 24 × 2 | 二連斬り。二撃目まで間合いを離して反撃 |
| 赤鬼（ボス） | 1500 | 36 | 金棒による半径6mの叩きつけ。赤い予告円の外へ退避 |

赤鬼は体力が半分以下になると激昂し、移動・攻撃準備・攻撃後の復帰が速くなり、叩きつけの威力が1.25倍になります。将軍と赤鬼には専用の体力バーと攻撃予告を表示します。

## 検証

Node.js 18以降で実行します。追加パッケージのインストールは不要です。

```sh
npm test
```

または個別に実行できます。

```sh
node tests/combat.cjs
node tests/projectiles.cjs
node tests/encounters.cjs
```

テストは実際のゲームコードをBabylon.jsのNullEngineで実行し、貫通上限、遮蔽物、爆風、クールタイム、突進、二連斬り、赤鬼の激昂、訓練標的の復活、全ステージ攻略などを検証します。画面の描画やブラウザ固有のPointer Lock動作は、ブラウザで確認してください。

## 配信

`dist/` を静的サイトの公開ディレクトリとして設定してください。サーバー処理や秘密鍵、環境変数は必要ありません。既存のSitesサービス固有の設定は、このGitHubリポジトリには含めていません。
